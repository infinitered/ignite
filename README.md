# Expo App Starter

> A FAANG-quality, SaaS-ready, context-engineered React Native + Expo starter template. Clone-and-go for new projects.

## What this template gives you

A production-grade foundation for any new RN + Expo app: opinionated stack, encoded conventions (Biome / Husky / CI / generators), pre-wired observability, accessibility-first primitives, and context-engineering files that steer Claude / Cursor / Codex / Gemini / Copilot toward house standards by default. The bar: code generated by any AI tool — even when "vibe coded" — defaults to FAANG-senior-level quality, because the rules are encoded in tools, not just docs.

## Quickstart

```bash
# 1. Clone & set up
git clone <repo-url> my-app && cd my-app
corepack enable
pnpm setup                              # installs deps, husky, copies .env.example → .env.local
pnpm rename MyApp --bundle-id com.your.app

# 2. Configure env
# Edit .env.local with SENTRY_DSN, POSTHOG keys, EXPO_PUBLIC_API_URL.
# (See .env.example for the full list.)

# 3. Run
pnpm ios            # or: pnpm android, pnpm web

# 4. Generate features
pnpm gen feature Profile

# 5. Before each PR
pnpm before-pr      # lint + typecheck + test
```

## Stack at a glance

- **Runtime**: Expo SDK 55 · RN 0.83 · React 19 · Hermes + New Architecture
- **Language**: TypeScript 5.9 (strict + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`)
- **Package manager**: pnpm 9 (with `node-linker=hoisted` for Expo)
- **State**: Zustand (with MMKV-backed persist) + TanStack Query (server state)
- **HTTP**: axios via `@/lib/api` (auth + error interceptors)
- **Forms**: React Hook Form + Zod
- **Styling**: NativeWind v4 + tailwind-variants (theme tokens in `tailwind.config.js`)
- **Lists**: `@shopify/flash-list` only (FlatList banned)
- **Images**: `expo-image` only (RN Image banned)
- **Storage**: MMKV (non-secret) + expo-secure-store (tokens)
- **Observability**: Sentry · PostHog (analytics + feature flags) · NetInfo
- **Lint/format**: Biome (replaces ESLint + Prettier)
- **Testing**: Jest + RTL · MSW · Maestro (E2E)
- **CI/CD**: GitHub Actions (ci · security · a11y · eas-build) · Dependabot
- **Build**: EAS · OTA via expo-updates

## Project structure

```
app/
├── components/         primitives (Button, Text, TextField, Screen, Card, ListView, Icon, Image, OfflineBanner, ErrorState, EmptyState, LoadingState)
├── screens/{feature}/  feature-grouped screens
├── navigators/         React Navigation
├── hooks/              cross-cutting hooks
├── services/           external clients (analytics, sentry, …)
├── stores/             Zustand stores
├── queries/            TanStack Query hooks per resource
├── lib/                pure utilities (api [axios], queryClient, storage, secureStorage, network, logger, fonts, cssInterop)
├── i18n/               translations + i18n init
├── types/              shared TS types
├── config/             env.ts (Zod-validated)
└── utils/              legacy bucket; prefer lib/

.claude/{skills,commands,agents,settings.local.json}   # Claude Code context
.cursor/{rules,commands}                                # Cursor IDE rules + commands
.agents/skills/                                         # Real skill content (symlinked at .claude/skills)
CLAUDE.md  AGENTS.md  GEMINI.md                         # Top-level system prompts for AI agents
.github/copilot-instructions.md                         # GitHub Copilot conventions

docs/                                                   # Architecture, standards, deployment, testing, …
docs/decisions/                                         # ADRs
```

Full architecture map: [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md).

## Key conventions (the short list)

- One opinionated way per concern. **Constraints are features.**
- Server state via TanStack Query; UI state via Zustand. **Never duplicate.**
- Auth tokens via `expo-secure-store` only. Non-secret prefs via MMKV.
- All HTTP via `@/lib/api`. Direct `axios`/`fetch` blocked by Biome.
- Theme tokens in `tailwind.config.js`. **No hardcoded colors / spacing.**
- All user-visible strings via i18next. **No hardcoded English in JSX.**
- Every Pressable: `accessibilityRole` + `accessibilityLabel`.
- Every screen handles **all four UI states**: loading, empty, error, populated.
- Lists with > 30 items: `<ListView />` (FlashList) with `estimatedItemSize`.

The full rules — and *why* each exists — live in [`CLAUDE.md`](./CLAUDE.md).

## Common scripts

| Script | What it does |
| --- | --- |
| `pnpm ios` / `pnpm android` / `pnpm web` | boot the dev sim |
| `pnpm gen <kind> <Name>` | scaffold (component, screen, hook, store, service, query, navigator, feature) |
| `pnpm rename <Name> --bundle-id …` | rename the app + bundle identifiers |
| `pnpm setup` | one-shot post-clone bootstrap |
| `pnpm before-pr` | lint + typecheck + tests (run before opening any PR) |
| `pnpm test:e2e` | Maestro E2E suite |
| `pnpm bundle:analyze` | inspect JS bundle composition |
| `pnpm bundle:check` | bundle-size budget gate |
| `pnpm doctor` | expo-doctor environment health check |

## Pre-flight checklist (before your first commit)

- [ ] `.env.local` filled in (`SENTRY_DSN`, `POSTHOG` keys, `EXPO_PUBLIC_API_URL`, `EXPO_PUBLIC_EAS_PROJECT_ID`)
- [ ] EAS secrets set: `EXPO_TOKEN`, `SENTRY_AUTH_TOKEN`, `SENTRY_ORG`, `SENTRY_PROJECT` (in CI / `eas secret:create`)
- [ ] App icon & splash updated in `assets/images/`
- [ ] `pnpm rename` run with your real app name + bundle id
- [ ] Sentry project created + DSN configured
- [ ] PostHog project created (optional but recommended)
- [ ] CODEOWNERS updated in `.github/CODEOWNERS`
- [ ] `gitleaks` installed locally (`brew install gitleaks`) for pre-commit secret scanning

## Context engineering

Any AI tool used in this repo picks up the conventions automatically:

- **Claude Code** loads `CLAUDE.md` at session start; the 8 skills in `.claude/skills/` and 7 slash commands in `.claude/commands/` are available immediately. Try `/onboard` to ground a fresh session.
- **Cursor** loads `.cursor/rules/*.mdc` (six glob-scoped rule files: core, native-app, testing, security, styling, accessibility) and `.cursor/commands/pr.md`.
- **Codex / Aider / Cline / Antigravity** discover `AGENTS.md` (which delegates to `CLAUDE.md`).
- **Gemini CLI** loads `GEMINI.md`.
- **GitHub Copilot** loads `.github/copilot-instructions.md`.

Edit the rules in one place; they propagate everywhere.
